\# Car Market Trends Analysis with Car Dekho Data



\## Problem Statement

The used-car market contains vehicles with diverse prices, fuel types, transmission types, and usage levels. This project analyzes historical Car Dekho data to identify market trends and factors influencing used-car selling prices.



\## Technologies Used

\- Python 3

\- Pandas \& NumPy

\- Matplotlib \& Seaborn



\## Project Structure

\- `car\_market\_analysis.py`: Main data analysis script.

\- `1776311302-P3-Car Market Trends Analysis with Car Dekho Data.csv`: Dataset.

\- `selling\_vs\_present\_price.png`: Price vs Present price scatter plot.

\- `price\_by\_fuel\_type.png`: Box plot of prices across fuel types.

\- `correlation\_heatmap.png`: Feature correlation heatmap.



\## Key Insights

1\. \*\*Present Ex-Showroom Price\*\* has the strongest positive correlation (\~0.88) with final selling price.

2\. \*\*Automatic transmission\*\* vehicles command higher average resale values than manual equivalents.

3\. \*\*Diesel vehicles\*\* display higher median selling prices compared to petrol and CNG options.
